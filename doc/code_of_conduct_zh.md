# 行为准则

Access WeChat Article 是一个面向学习、科研和本地材料整理的项目。我们希望项目讨论保持直接、友好、具体、尊重事实，并重视法律、平台规则和研究伦理。

## 1. 我们鼓励

- 清楚描述问题、复现步骤、运行环境和已尝试的方法。
- 对代码、文档、测试和设计提出具体建议。
- 尊重不同使用场景、技术水平和研究背景。
- 在涉及平台规则、法律、伦理和数据安全时保持谨慎。
- 对不确定的信息明确说明，不编造接口能力、实验结果或项目功能。

## 2. 我们不接受

- 人身攻击、侮辱、骚扰、歧视或恶意嘲讽。
- 发布他人的个人信息、Cookie、证书、数据库、聊天记录、文章归档或敏感日志。
- 鼓励绕过平台规则、侵犯版权、批量滥用接口、规避账号风控或进行不合规采集。
- 要求维护者协助处理不合规用途。
- 在没有证据的情况下声称项目具有不存在的能力或效果。

## 3. Issue 和 Pull Request 讨论

提交问题或贡献时，请尽量：

- 使用清晰标题。
- 描述你的目标和当前阻塞。
- 提供脱敏后的最小复现信息。
- 把多个独立问题拆成多个 Issue。
- 讨论代码时聚焦事实、证据和可验证结果。

如果讨论中出现敏感信息，请立即编辑删除，并提醒维护者。

## 4. 维护者处理方式

维护者可以根据情况：

- 编辑或删除包含敏感信息的内容。
- 要求提交者补充复现步骤或脱敏材料。
- 关闭重复、无关或不符合项目目标的问题。
- 拒绝会增加合规风险或安全风险的贡献。
- 限制持续破坏讨论秩序的参与者。

## 5. 反馈方式

如果你遇到行为准则相关问题，请通过 Issue 或安全反馈渠道联系维护者，并尽量提供必要上下文。涉及隐私、安全或敏感数据时，不要在公开讨论中贴出细节。

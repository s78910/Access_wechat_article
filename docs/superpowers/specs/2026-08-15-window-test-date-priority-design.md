# 窗口测试日期优先设计

## 目标

保持现有标题提取、文章卡片识别、卡片坐标和滚动方式不变，将窗口测试改为由 UIA 日期组优先控制遍历范围。

## 日期标准化

- UIA 日期组中的“今天”“昨天”“星期一”等相对日期转换为运行当天对应的自然日。
- “8月2日”等无年份日期按主页倒序语义推断年份。
- “2024年4月25日”等完整日期直接转换为 `YYYY-MM-DD`。
- 无法转换日期的日期组不参与日期筛选，并写入诊断记录。

## 模式语义

### 日期范围

- 任务数量固定为 `0`，表示不限制数量。
- 跳过晚于截止日期的日期组。
- 记录起始日期与截止日期之间的全部文章卡片，包含两个边界日期。
- 遇到早于起始日期的日期组后停止。

### 截止日期

- 任务数量固定为 `0`，表示不限制数量。
- 从当前页面第一篇可用文章开始记录。
- 记录到截止日期当天，包含截止日期。
- 遇到早于截止日期的日期组后停止。

### 起始日期

- 任务数量默认恢复为 `20`，并允许在 `1-20`之间调整。
- 日期定位阶段只解析可视 UIA 日期组，不提取标题、卡片坐标、点击点或文章记录。
- 找到目标日期时，从目标日期组开始记录。
- 目标日期当天没有文章时，从第一个早于目标日期的日期组开始记录。
- 定位完成后才执行完整卡片解析，并按任务数量继续向下记录。

## 边界处理

- 日期组仍按主页从新到旧的顺序处理。
- 日期定位阶段滚动后没有日期变化时，沿用现有等待与回弹机制。
- UIA 树客观上包含文章节点，但日期定位阶段不读取或生成文章卡片业务数据。
- 标题提取逻辑本次不修改。
